# 03 — 月次予算を設定し消化状態を確認する

**Feature:** personal-kakeibo

**PBI:** PBI-0004（`pbl/items/PBI-0004-monthly-budget-and-status.md`）

**作るもの:** 個人利用者が対象月の月次予算を画面で設定し、確定済み支出に基づく予算消化状態（余裕・逼迫・超過、または未設定）を同一アプリ内で確認できる。

**Blocked by:** personal-kakeibo-02-transaction-lifecycle.md

**Status:** completed

**Triage:** ready-for-agent

- [x] 対象年月ごとに正の金額の月次予算を設定できる
- [x] 正でない金額は拒否され、同一年月への再設定は上書きになる
- [x] 消化は対象月の確定済み支出合計のみを対象とする（収入・下書き・取消は含めない）
- [x] 予算あり時は余裕（80%未満）／逼迫（80%以上かつ予算以下）／超過を表示する
- [x] 予算未設定時は「未設定」と分かり、三態のいずれにもしない
- [x] 主要画面で対象月が分かり、当月中心に表示または切り替えができる（D12 の当該部分）
- [x] 消化状態が進捗表示または同等で一目で分かる（D13 の当該部分）

# 予約管理用語

| 用語 | 定義 |
|------|------|
| 予約 | 日時・人数・顧客に紐づく予約本体。提供リソースの割当と予約ステータスを持つ |
| 予約枠（スロット） | 受付可能な時間帯と定員。営業時間・休業を前提に成立する |
| 提供リソース | 席・スタッフ・メニュー枠など、予約を載せる割当対象 |
| 顧客 | 予約者。氏名・連絡先など最小の連絡情報を持つ |
| 予約ステータス | 予約の扱い状態。受付 → 確定 → 来店／完了／キャンセル、ならびに却下／保留の最小扱いを含む |
| 空き確認〜予約確定 | 空きを確認して申し込み、店舗側が確定（または却下／保留）するまでの一連の扱い |
| 営業時間・休業 | 予約枠が成立するための前提。休業日には受付可能な枠を出さない |

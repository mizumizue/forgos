# 個人美容室予約 — 用語

業態は **1人運営の個人美容室**（チェア1・スタイリスト＝店主のみ）。予約単位は席在庫ではなく、施術メニューの所要時間ぶんの連続時間である。

| 用語 | 定義 |
|------|------|
| 施術メニュー | 来店客が選ぶ施術の種類。所要時間（分）を必須で持つ |
| 所要時間 | 施術メニューが店主カレンダー上で占有する連続時間の長さ。片付け等の短い準備は所要に内包し、独立バッファとしては扱わない |
| 営業時間 | 曜日ごとに受付可能な開始・終了時刻の前提 |
| 定休 | 予約を受け付けない休業日（例: 特定曜日） |
| 休憩ブロック | 営業日内で受付しない連続時間帯（例: 昼休憩） |
| 空き枠 | 選んだ施術メニューの所要時間ぶん、営業時間内かつ定休・休憩・既存予約と重ならない連続時間の開始可能区間 |
| 予約 | 施術メニュー・空き枠（開始時刻と所要）・顧客最小情報・予約状態を束ねた申込単位 |
| 顧客 | 申込に必要な最小の来店者情報（氏名・連絡先） |
| 申請 | 来店客が申し込んだ直後の予約状態。店主の確定前 |
| 確定 | 店主が申請を受け入れた予約状態 |
| 完了 | 来店・施術が終わった予約状態 |
| キャンセル | 予約が取り消された状態。当該時間塊は再び空き枠として申込可能になる |
| 本日台帳 | 店主が当日の予約を時間順に把握し、申請の確定や状態確認を行う導線上の責務範囲 |
| キャンセルポリシー | 来店客が申込時に確認できるキャンセル条件の文面（課金・配信は含まない） |

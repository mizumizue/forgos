# 家計簿用語

| 用語 | 定義 |
|------|------|
| 口座 | 支払元または入金先（現金・銀行など）。取引が紐づく場所。 |
| カテゴリ | 収入または支出を分類するラベル。 |
| 取引 | 収入または支出の1件。口座・カテゴリ・金額・発生日を持つ。 |
| 下書き | まだ家計実績に含めない取引の状態。 |
| 確定 | 家計実績に含める取引の状態。予算消化の計算対象になる。 |
| 取消 | 取引を無効化した状態。家計実績・予算消化の対象外。 |
| 月次予算 | 対象年月に対して設定する支出の上限感（金額）。 |
| 予算消化状態 | 対象月の確定済み支出と月次予算から導く見え方。余裕・逼迫・超過のいずれか。 |
| 余裕 | 確定済み支出の合計が月次予算の 80% 未満。 |
| 逼迫 | 確定済み支出の合計が月次予算の 80% 以上かつ予算額以下。 |
| 超過 | 確定済み支出の合計が月次予算を超える。 |

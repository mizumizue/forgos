## Actors と主表面方針

| Actor | 主表面（≤3 のうち） | 入口の役割 |
|-------|---------------------|------------|
| **講師（オーナー）** | S1 レッスン帳（週ストリップ） | 固定枠の正本・当日出欠・実施時間の確定 |
| **講師（オーナー）** | S2 振替キュー | 保護者申請の可否判断・同レベル空き枠への確定 |
| **保護者／受講生** | S3 マイ枠 | 在籍枠の確認・期限内欠席連絡・振替希望の申出 |

**Actor-split 原則:** 講師は「全クラス・全生徒の編成権」、保護者は「自子（または本人）の枠のみ」。保護者面に他生徒の氏名・出欠は出さない（在籍枠の「空き席数」だけ共有）。講師 override（期限後受理・再振替不可の例外）は S2 のみ。

## 主表面ごとの Attention（視線優先）と情報主従

### S1 — 講師レッスン帳（週ストリップ）

| 優先度 | 視線ターゲット | 主従の理由 |
|--------|----------------|------------|
| **1（最上）** | **今日の縦帯ハイライト列** — 現在時刻に近いクラス枠カード | 講師はレッスン直前・直後に「今どの枠か」を 0.5 秒で掴む。週全体より「今日」が主役（sector brief OP-1: 毎週固定枠への出欠記録） |
| **2** | **各枠カード内の座席リング（定員 2〜3）** — 出席／欠席／未確定の色分け | 集合個人レッスンでは「誰が来るか」が実施時間（OP-4: 1名20分・2名45分・3名60分）を決める。氏名リストより座席の埋まり具合を先に見せる |
| **3** | **実施時間バッジ**（枠下部・人数連動で自動更新） | 時間短縮ルールは教室の差別化ポイント。未確定時はグレー、確定後に太字（田中 [S2] ルールを視覚化） |
| **従** | 曜日ヘッダ・週送り・月謝ステータスドット | ナビと事務補助。レッスン中は視界の外縁（A5 はアラート時のみ S1 上端に細バナー） |

### S2 — 講師振替キュー

| 優先度 | 視線ターゲット | 主従の理由 |
|--------|----------------|------------|
| **1** | **期限切れ間近バッジ付き申請カード**（前日 18:00 等・教室設定値） | 石橋型期限 [S1] 違反リスクが講師の判断コスト最大。新着順ではなく「残時間昇順」 |
| **2** | **同レベル空き枠チップ列**（定員空きのみ・タップで確定） | OP-2 の手作業（カレンダー照合→LINE 返信）をチップ選択に置換。空きなしは明示的に「同レベル空きなし」で終了 |
| **3** | **再振替不可／月 1 回上限の規約ラベル** | 申請ごとに T2・T3 条件を短文表示。override トグルはカード最下部（通常は隠す） |
| **従** | 申請者の在籍枠・連絡チャネル（LINE／電話） | 判断材料だが主ボタンより下。チャネルは A3 の記録用 |

### S3 — 保護者／受講生マイ枠

| 優先度 | 視線ターゲット | 主従の理由 |
|--------|----------------|------------|
| **1** | **在籍固定枠カード**（曜日・時刻・クラス名・レベル帯） | 月謝＝固定枠の確保（T1）。保護者の第一関心は「うちの子の曜日は何時か」 |
| **2** | **今週の回次ステータス**（予定／欠席連絡済／振替確定／振替不可） | 欠席連絡と振替の結果を 1 行で追える。複数画面に分けない |
| **3** | **主 CTA「欠席を連絡する」／「振替を希望する」**（状態で出し分け） | OP-1・OP-2 の入口。期限内のみ活性。期限後は「講師に相談」リンク（電話／LINE 外部） |
| **従** | 教室からのお知らせ・規約全文 | 折りたたみ。初回以外は視線に入れない |

## Genre Look（領域固有の見た目 — ≥3 要素）

| # | 要素 | 具体 | ドメイン根拠 |
|---|------|------|--------------|
| G1 | **座席リング（2〜3 席）** | 各クラス枠内にピアノ前の半円配置アイコン。空席は鍵盤の白鍵色 `#F5F0E8`、出席確定は温かいアンバー `#C49A6C`、欠席は消音ペダル灰 `#8B8B8B` | 定員制グループレッスンは「席」が資源。リスト UI では「誰が欠席すると何分になるか」が伝わりにくい（OP-4） |
| G2 | **週ストリップ＋今日の縦帯** | 横スクロールの 7 列グリッド。今日列は楽譜台の木目 `#E8DCC8` の淡い縦帯＋左端に五線譜の細線（装飾 1 本のみ） | 習い事は「毎週同じ曜日」が体験の核。月カレンダーより週の繰り返しが主（A1 固定枠） |
| G3 | **人数連動の実施時間バッジ** | 枠カード右下にメトロノーム拍子風ラベル（例 `♩= 45min`）。1 名時は自動で `20min` に縮小アニメ | ピアノ田中の欠席時短縮 [S2] を教室の顔として見せる。汎用予約アプリの「60min 固定」表示と差別化 |
| G4 | **ウォームスタジオパレット** | 背景 `#FAF7F2`（練習室の壁）、アクセント `#6B4E71`（消した紫＝ピアノカバー布）、警告は譜めくり `#D4A574` で赤は期限切れのみ | コールドブルーの SaaS 管理画面を避け、保護者にも「教室の延長」に感じさせる（C7） |
| G5 | **規約インラインラベル** | 「前日 18:00 まで」「同レベルのみ」「再振替不可」を小さな譜めくりタグで常時表示（折りたたみ不可） | 石橋・KASE の期限・回数制限 [S1][S3] は UI の装飾ではなく判断材料 |

## 主要ジョブの画面遷移（分岐・戻る含む）

### J1 — 保護者：期限内の欠席連絡（OP-1）

```text
S3 マイ枠
  → [欠席を連絡する]（今週の回が「予定」のときのみ活性）
    → 欠席連絡シート（回次・理由・連絡チャネル選択）
      → [送信]
        → 成功: S3 に戻る（ステータス「欠席連絡済」）
        → 期限切れ検出: エラー文言＋「講師に相談」外部リンク → S3 に戻る
      → [キャンセル] → S3 に戻る
  ← ブラウザ戻る: S3（下書きは破棄）
```

**分岐:** 既に欠席連絡済 → CTA 非活性、代わりに「振替を希望する」へ。  
**講師側反映:** S1 当該枠の座席が欠席色に更新（リアルタイムまたはリロード）。

### J2 — 保護者：振替希望 → 講師確定（OP-2）

```text
S3 マイ枠（欠席連絡済）
  → [振替を希望する]
    → 振替希望シート
      → 同レベル空き枠チップあり
        → チップ選択 → [申請する]
          → S3（ステータス「振替申請中」）＋タイムライン 1 行追加
      → 空き枠なし
        → 「今月は同レベルの空きがありません」＋規約タグ表示
        → [閉じる] → S3
      → [キャンセル] → S3

講師 S2 振替キュー（新規申請カード）
  → カード展開（申請者・希望枠・期限バッジ）
    → [この枠で確定]
      → 確認ダイアログ（再振替不可の再表示）
        → [確定] → S2（カード「処理済」へ）＋ S1 振替先枠に座席追加
        → [戻る] → S2 カード
    → [却下]（空きなし・規約外）
      → 理由選択 → S2（カード「不可」）→ 保護者 S3 が「振替不可」
    → [override 受理]（期限後・講師のみ）
      → 理由必須 → 同上確定フロー

保護者 S3
  ← 確定後: ステータス「振替確定」＋新しい日時カード
  ← 却下後: 「振替不可」＋規約リンク
```

**戻る:** S2 の各ダイアログに「戻る」。S3 は常にマイ枠がホーム（深い階層なし）。

### J3 — 講師：当日出欠確定と実施時間（OP-1 + OP-4）

```text
S1 レッスン帳（今日列フォーカス）
  → クラス枠カードタップ
    → 座席リング詳細シート（各生徒: 出席／欠席／未確定トグル）
      → トグル変更のたび実施時間バッジがリアルタイム更新（1→20, 2→45, 3→60）
      → [レッスンを確定]
        → 確定後カードはロック（グレーアウト編集）
        → [戻る] → S1
      → [戻る]（未確定のまま） → S1

分岐:
  - 欠席だが振替申請なし: 座席欠席色のまま確定可（月謝は発生 — T1、表示のみ）
  - 振替確定済み生徒が別枠にいる: 当該枠は「振替 outbound」表示、座席は空席扱い
  - 全員欠席: バッジ「休講扱い」提案 → 講師確認 → 実施時間 0 またはキャンセル記録
```

**週送り:** S1 ヘッダ [← 前週] [今週] [次週 →] — 過去確定枠は読み取り専用。

### J4 — 講師：振替キューからの横断（S1 ↔ S2）

```text
S1 枠カード内「振替 1 件」リンク
  → S2 該当カードへスクロール（同一セッション内アンカー）
S2 処理完了
  → [レッスン帳で確認] → S1 の振替先週へジャンプ
```

**矛盾チェック（C9）:** 保護者は S3 のみで申請。講師の確定は S2 のみ。S1 は出欠正本だが振替確定ボタンは置かない（閲覧＋ショートカットのみ）。

## デモ完了の見え方（demo-grade）

- 保護者が S3 から欠席連絡 → 振替申請 → 講師が S2 で確定 → 保護者 S3 に反映、まで画面のみで完遂
- 講師が S1 で当日の座席トグル → 人数連動時間バッジ確定、まで完遂
- 他生徒の個人情報は保護者面に出ない
- 月謝・LINE・決済は触れない（見送りどおり）

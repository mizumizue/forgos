# Scope — run `20260810-kakeibo`

## テーマ

個人向けの家計簿の正式プロダクトのデモ版として、収入・支出の記録から月次予算の消化把握までを画面で一通り使えるようにする。

## 作業ブランチ

- ブランチ: `validation/20260810-kakeibo`
- 起点: `main`（コミット `95b730f`。本 worktree では `main` が他 worktree 占有のため、同 tip から新規ブランチを作成。他 validation ブランチの流用ではない）

## 通常利用形態

**画面**（Web UI）。ドメイン核ライブラリ単体で止めず、主要ユースケースを画面操作で完遂する。

### demo-grade の画面 UC（スコープ内）

1. 口座・カテゴリを画面から用意する
2. 取引を画面で下書き登録し、確定する（必要なら取消する）
3. 月次予算を画面で設定する
4. 確定済み取引を踏まえ、予算消化状態（余裕／逼迫／超過）を画面で確認する

上記 1–4 が demo-grade の主要導線であり、画面だけで完遂できること。

## スコープ内（やること）

- 個人が自分の家計を記録・把握するためのデモ版 UI
- 下記ドメイン骨格の採用概念に沿った最小の画面導線（CRUD＋ワークフロー／状態の可視化）
- テーブルステークス・ジャンル見た目は後工程（Spike Source）で根拠付けし、ここでは膨らませない

## スコープ外（やらないこと）

- 法人会計
- 投資の記録・評価
- 確定申告連携
- レシート OCR
- 定期取引の自動登録（見送り。理由はドメイン骨格参照）
- 家計の複数人共有（見送り。理由はドメイン骨格参照）
- 本番運用相当の認証・マルチテナント・課金・本格レポート

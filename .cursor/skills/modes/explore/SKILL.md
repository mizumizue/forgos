# Explore

あいまいさを **触って減らす**。正は一時的に sandbox。仕様の自動昇格はしない。

## ステップ

1. **疑問を1つに絞る。** ユーザーの目的・制約を確認し、このセッションで答える疑問を一文で書く。完了条件: 疑問が1文で書けている。
2. **置き場を sandbox にする。** `sandbox/<topic>/` に実装する。`apps/` の通常 feature に混ぜない。完了条件: パスが sandbox 配下。
3. **最小スパイクを作る。** テストは任意。仕上げ・永続化・抽象化は疑問に答える分だけ。完了条件: 1コマンドで動く、または学習メモだけで十分ならメモがある。
4. **学習を残す。** 仮説・観測・次アクションを `sandbox/<topic>/LEARNINGS.md`（または関連 PBI）に書く。完了条件: 学習メモが更新されている。
5. **Extract を提案する（強制しない）。** 仕様化すべき知見があれば草案を提示し、昇格は人間ゲート（`specs/L1/extract-gate.md`）に従う。完了条件: 昇格するか保留かが明示されている。

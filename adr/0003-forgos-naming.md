# 正式名称を ForgOS（slug: forgos）とする

## 文脈

作業名は `ai-dev-framework` で、正式名称は未定だった。工程 OS としての核を短く覚えやすいブランド名にしたい。

## 決定

1. 表示名: **ForgOS**（副題: ForgOS — AI 工程 OS）
2. リポジトリ slug: **`forgos`**
3. 核は工程 OS、メタファーは鍛冶（forge を縮めて OS と接着）
4. GitHub リポジトリを `ai-dev-framework` から `forgos` に改名する

## 代替案

- `ForgeOS` — 明瞭だが被りやすく、もじりが弱い
- `ModeForge` / `TemperOS` — 正確または体験に合うが、今回の「短いもじり」優先とずれる
- 説明的 slug（`ai-process-os`）— 分かりやすいがブランド性が弱い

## 却下理由

上記。

## 決め事への反映

ブランド名は L1 規範ではない。案内は README / CONTEXT / AGENTS に反映。

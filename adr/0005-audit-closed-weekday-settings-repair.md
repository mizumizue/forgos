# Audit 戻し修復: 店設定に定休（曜日）編集を足す

実証ループ工程6（Audit）で、個人美容室予約デモの **重大 Gap** として「定休を画面で設定できない」を検出し、Stop 内の Implement 戻し（ラウンド1）で修復した。

## 文脈

- 決め事 D3 / UC `manage-business-hours` / PBI-0002 AC-5 / issue 01 は、店主が **営業時間・定休・休憩** を設定できることを要求する。
- ドメインは `closedWeekdays` を空き枠生成に既に反映していたが、店設定面は開店・閉店・休憩のみで、定休はヒント文言止まりだった。
- DEMO-UX Audit の重大候補「仕様乖離」に該当するため、指摘のみで止めず戻し修復した。

## 決定

1. 店設定面の営業前提ブロックに **定休（曜日）トグル** を置き、`updateBusinessHours` の `closedWeekdays` を保存する。
2. ドメイン単体に「定休に含めた曜日は枠ゼロ」の回帰を追加する。
3. 仕様（L3）は変更しない（実装が What に追いつく向き）。

## 代替案

| 案 | 却下理由 |
|----|----------|
| 定休をデモ固定のまま仕様を狭める | ユーザー明示の Specify なし。AC-5／D3 を書き換えるのは Audit 権限外 |
| ドメイン API のみで「設定できる」とみなす | 通常利用形態は画面。UC は店設定面での設定を要求 |

## 結果

- 修復後の重大 Gap: ゼロ（軽微のみ残置）

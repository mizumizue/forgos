# リポ内ルータースキル `/ask-me` を置く

## 文脈

ForgOS のモード・パイプライン・モード外スキル（`/tdd` `/assure` 等）が増え、ユーザー起動の認知負荷が上がった。個人環境の `/ask-me` はホームスキル向けで、本リポの正本経路（draft→…→audit）とは一致しない。

## 決定

1. リポに **ユーザー起動ルーター** `.cursor/skills/ask-me/SKILL.md`（`/ask-me`）を置く。
2. 役割は到達先の名前とタイミングの案内のみ。他のユーザー起動スキルを代理実行しない。
3. 正本のモード表は `AGENTS.md` のまま。`/ask-me` は覚えやすさのための入口。
4. L1 は変更しない。

## 代替案

- AGENTS.md だけに頼る → チャットからスキルとして起動しにくい
- モデル起動の巨大メニュー → 毎ターンのコンテキスト負荷
- ホームの `/ask-me` を流用 → ForgOS 経路と食い違う

## 却下理由

上記のとおり。

## 決め事への反映

製品決め事は増やさない。導線は `AGENTS.md` / `CONTEXT.md` / `README.md`。
